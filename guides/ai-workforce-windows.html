## 4. Practical Windows Performance Cleanup Tips

1. **Disable Startup Programs**
- Press `Ctrl+Shift+Esc`, go to the **Startup** tab, and disable non-essential apps.
- Use the built-in **Settings ? Apps ? Startup** for a cleaner interface.

2. **Clear Temporary Files**
- Run `cleanmgr` (Disk Cleanup) and select all temporary folders.
- Add `C:\Users\<user>\AppData\Local\Temp` to the list.

3. **Registry Optimization**
- Use **PC Cleaner Pro** (included in the bundle) to scan for orphaned keys.
- Backup the registry before applying changes.

4. **Update Drivers**
- Open **Device Manager**, right-click on GPU and network adapters, and choose **Update driver**.
- For NVIDIA/AMD GPUs, download the latest drivers from the vendor�s site.

5. **Adjust Power Settings**
- Set **Power Plan** to **Balanced** or **Power Saver** when on battery.
- Disable **Intel SpeedStep** if you need maximum performance on AC power.

6. **Manage Background Services**
- Open `services.msc` and set non-essential services to **Manual** or **Disabled**.
- Pay special attention to services like **Windows Search** and **Superfetch** if you�re on a low-RAM machine.

7. **Use a Lightweight Browser**
- Switch to Microsoft Edge (Chromium) or Brave for better memory management.
- Disable extensions that consume resources.

8. **Regularly Reboot**
- Even a quick restart clears memory leaks and resets drivers.
