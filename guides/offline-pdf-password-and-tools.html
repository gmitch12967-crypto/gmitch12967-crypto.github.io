## 3. SHA‑256 Verification

1. **Download the ZIP** from the official link below.
2. Open a terminal (macOS/Linux) or PowerShell (Windows).
3. Navigate to the folder containing the ZIP.
4. Run the following command (replace `bundle.zip` with the actual file name):

```bash
sha256sum bundle.zip # macOS/Linux
certutil -hashfile bundle.zip SHA256 # Windows PowerShell
```

5. Compare the output to the value listed in `SHA256SUMS` inside the ZIP.
- If they match, the file is authentic.
- If they differ, re‑download or contact support.

> **Why this matters:** Guarantees that the bundle hasn’t been tampered with and that you’re running the exact code the author intended.

## 5. Step‑by‑Step Use Cases

### 5.1 Shrink an Oversized PDF to ≤1 MB

1. Open **PDF‑Shrink**.
2. Drag the PDF into the window or click **Open File**.
3. Select **Target Size**:
- *1 MB* (default)
- *2 MB* (if you need a slightly larger file)
4. Click **Compress**.
5. The tool displays the new size and a preview.
6. Click **Save As** to choose the destination folder.

> **Tip:** For legal documents, keep the *“Preserve Quality”* toggle on to avoid losing text readability.

### 5.2 Combine Multiple Tax & Legal PDFs

1. Open **PDF‑Merge**.
2. Drag all PDFs into the list area.
3. Use the **Reorder** arrows to set the exact sequence.
4. (Optional) Click **Add Password** to encrypt the merged file.
5. Click **Merge**.
6. Save the combined PDF.

### 5.3 Split a Large PDF into Sections

1. Open **PDF‑Split**.
2. Load the PDF.
3. Choose **Split by Page Range** (e.g., 1‑10, 11‑20).
4. Or choose **Split by Bookmark** to automatically split at each bookmark.
5. Click **Split**.
6. Export each part to the desired folder.

### 5.4 Scrub HIPAA/PII with AirGap Redact Pro

1. Launch **AirGap‑Redact‑Pro**.
2. Drag the PDF or DOCX containing sensitive data.
3. The tool auto‑detects common PII/PHI patterns (SSN, DOB, phone, email).
4. Review the highlighted areas.
5. Click **Redact** to permanently remove them.
6. (Optional) Choose **Redaction Style**: black box, gray box, or custom image.
7. Save the redacted file.

> **Security Note:** All redaction happens locally; no data leaves your machine. The tool uses AES‑256 encryption for temporary buffers.

### 5.5 Clean Messy CSV Spreadsheets

1. Open **CSV‑Cleaner**.
2. Drag the CSV file or click **Open**.
3. The tool auto‑detects:
- Duplicate rows
- Inconsistent column headers
- Mixed data types (e.g., numbers stored as text)
4. Use the **Fix** panel to apply corrections:
- *Remove Duplicates*
- *Standardize Headers*
- *Convert Numbers*
5. Click **Apply**.
6. Save the cleaned CSV.

### 5.6 Fix ATS‑Unfriendly Resumes

1. Launch **Resume‑Fixer**.
2. Drag the resume file (PDF, DOCX, or RTF).
3. The tool parses the document and identifies:
- Hidden formatting (tables, columns) that ATS can’t read.
- Non‑standard fonts or symbols.
4. Click **Convert to ATS‑Friendly**.
5. Review the plain‑text preview.
6. Export as **Plain Text (.txt)** or **Re‑PDF** (cleaned).

> **Result:** Your resume will be readable by Applicant Tracking Systems and recruiters alike.
