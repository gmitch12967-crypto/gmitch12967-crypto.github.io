## 3️⃣ How Each Tool Works (Step‑by‑Step)

### 🔹 1. Shrink Oversized PDFs (≤ 1 MB / 2 MB)

1. **Launch** `AirGap PDF Shrinker.exe`.
2. **Drag & drop** your PDF onto the window.
3. Choose **Target Size**:
- **1 MB** (high compression)
- **2 MB** (balanced)
4. Optional: tick **Preserve Images** to keep high‑resolution graphics for legal filings.
5. Click **Compress** – the tool runs a local OCR‑aware down‑sampling algorithm, removes unused objects, and rewrites the PDF.
6. The **compressed file** appears next to the original with `_shrunk` appended.

> **Result:** PDFs that once weighed 8 MB can be reduced to under 1 MB without noticeable loss—perfect for email attachments or portal uploads.

### 🔹 2. Combine Private Tax & Legal PDFs

1. Open `AirGap PDF Merger.exe`.
2. **Add Files** → select all PDFs you need in the final order.
3. Use **Reorder** arrows if needed.
4. Click **Merge** → a single combined PDF is saved.
5. **Optional:** Enable **Bookmark Preservation** to keep each original file’s table of contents.

> **Result:** One tidy PDF for a client’s entire tax year or a case file, ready for secure sharing.

### 🔹 3. Split PDFs (e.g., separate contracts, individual tax returns)

1. Run `AirGap PDF Splitter.exe`.
2. Load the source PDF.
3. Choose **Split By:**
- **Page Range** (e.g., 1‑5, 6‑10)
- **Bookmarks** (auto‑splits at each bookmark)
4. Define an **output folder** and naming pattern (`{original}_part{n}`).
5. Click **Split**.

> **Result:** Instantly generate individual PDFs for each contract clause, invoice, or client without manual copying.

### 🔹 4. Scrub HIPAA / PII Identifiers – AirGap Redact Pro

1. Open `AirGap Redact Pro.exe`.
2. Drag the PDF(s) you need to cleanse.
3. Choose **Redaction Profiles:**
- **HIPAA** (SSN, DOB, MRN, PHI)
- **GDPR** (email, phone, address)
- **Custom** (add your own regex patterns).
4. Click **Scan** – the tool highlights every match.
5. Review the highlights; you can **exclude** false positives.
6. Hit **Redact** – the data is permanently removed (pixelated or black‑boxed) and the PDF is saved as `_redacted`.

> **Result:** Fully compliant PDFs ready for public distribution, audit, or legal discovery.

### 🔹 5. Clean Messy CSV Spreadsheets

**CSV Cleanser** handles:

- **Inconsistent delimiters** (comma vs. semicolon).
- **Trailing/leading whitespace**.
- **Broken line breaks** inside quoted fields.

**How to use:**

1. Launch `CSV Cleanser.exe`.
2. Drop your CSV file.
3. Choose **Auto‑Detect** or manually set the delimiter.
4. Click **Fix** – the tool rewrites a clean version (`_cleaned.csv`).

**CSV De‑Duplicator** (optional):

1. Open `CSV De‑Duplicator.exe`.
2. Load the cleaned CSV.
3. Select **Key Columns** (e.g., `Email`, `ID`).
4. Click **Remove Duplicates** – a deduped file (`_deduped.csv`) is created.

> **Result:** Ready‑to‑import spreadsheets for accounting software, CRM, or data analysis—no more “column shift” errors.

### 🔹 6. Fix ATS‑Ready Resumes 100 % Locally

**ATS‑Ready Resume Builder**:

1. Run `ATS Resume Builder.exe`.
2. Import your existing `.docx` or `.pdf` resume.
3. Choose a **Template** (Classic, Modern, Functional).
4. The tool automatically:
- Converts tables to plain text sections.
- Inserts standard headings (`Experience`, `Education`, `Skills`).
- Generates a **plain‑text version** (`.txt`) for ATS parsing.
5. Click **Export** → you receive three files:
- `resume_formatted.pdf` (human‑friendly)
- `resume_ats.txt` (ATS‑ready)
- `resume_word.docx` (editable).

**Resume Keyword Optimizer** (add-on):

1. Open `Resume Keyword Optimizer.exe`.
2. Paste the job description or select an industry list.
3. The tool scans your resume and **suggests** missing keywords.
4. Click **Inject** – keywords are added in context without breaking formatting.

> **Result:** A resume that passes every major ATS (iCIMS, Taleo, Greenhouse) while still looking polished to recruiters.
